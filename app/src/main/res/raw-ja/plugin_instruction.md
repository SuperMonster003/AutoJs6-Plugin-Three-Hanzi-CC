3-Hanzi CC は OpenCC ベースのオフライン中国語変換ツールで, 簡体字, 繁体字, 香港繁体字, 台湾繁体字, 日本語新字体の間でテキストを変換します. ランチャーから単独で使えるほか, AutoJs6 スクリプトにグローバルオブジェクト `opencc` を提供します.

### はじめに

1. ランチャーから 3-Hanzi CC を開き, "変換元テキスト" にテキストを入力するか, "貼り付け" をタップしてクリップボードから読み込みます.
2. "変換タイプ" で変換方向を選び, "変換" をタップします.
3. "変換結果" で結果を確認し, "コピー" または "共有" をタップして利用します.
4. AutoJs6 スクリプトではグローバルオブジェクト `opencc` を直接呼び出します. 使い方は下記を参照してください.

### 主な機能

- **14 種類の変換**: 簡体字, 繁体字, 香港繁体字, 台湾繁体字, 日本語新字体の間の主な変換方向をカバーします. "台湾用語" 付きのタイプは語句も置き換え, 例えば "鼠标" は "滑鼠" になります.
- **クイック編集**: "反転" は逆の変換方向に切り替え, "入れ替え" は変換元テキストと変換結果を入れ替え, "クリア" はテキストを消去します.
- **オフライン変換**: 変換は内蔵辞書を使って端末上で行われ, ネットワークは不要です. テキストがアップロードや保存されることはありません.
- **カスタマイズ**: 言語, ダークモード, テーマ色, ランチャーアイコンを変更できます. "変換タイプを記憶" をオンにすると, 次回開いたときに前回の変換タイプに戻ります.
- **プラグインツール**: AutoJs6 6.8.0 以降では `opencc_convert` ツールも提供し, MCP Server などのプラグインやスクリプトの `plugins.tools` から呼び出せます.

### スクリプトでの使い方

AutoJs6 スクリプトでは, インポートせずにグローバルオブジェクト `opencc` を使えます. 変換タイプごとに同名のメソッドがあり, `convert` でタイプを指定することもできます:

```js
console.log(opencc.s2t("汉字转换"));     // => 漢字轉換
console.log(opencc.t2s("漢字轉換"));     // => 汉字转换
console.log(opencc.s2twp("鼠标和软件")); // => 滑鼠和軟體
console.log(opencc.convert("汉字转换", "S2T")); // => 漢字轉換
```

- 変換タイプは大文字と小文字を区別しません (例: `S2T`, `S2TWP`, `HK2S`, `T2JP`). `s2jp`, `hk2tw` などの組み合わせメソッドは複数の変換を順に実行します.
- Node.js スクリプトでは `require('autojs6:opencc')` で読み込み, Bun スクリプトでは `host.opencc` を使います. メソッドは同じで, いずれも Promise を返します.

### 動作要件

- Android 7.0 以降. ランチャーから単独で使う場合, AutoJs6 は不要です.
- スクリプトで使うには AutoJs6 6.7.1 Alpha4 以降が必要で, "プラグインセンター" で本プラグインを有効にしておく必要があります.
- Node.js スクリプトには Node.js Runtime プラグイン 1.7.0 以降, Bun スクリプトには Bun Runtime プラグイン 0.2.6 以降が必要です. Bun Runtime の設定ページでは `text.opencc` をオンのままにしてください (既定でオン).
- ネットワーク権限はアプリの更新確認にのみ使います. "更新を自動的に確認" は既定でオンで, 12 時間に最大 1 回確認し, "設定" でオフにできます.

### よくある質問

**AutoJs6 なしでの利用**

ランチャーから 3-Hanzi CC を開けばテキストを変換できます. AutoJs6 が必要なのは, スクリプトから `opencc` を呼び出す場合だけです.

**`s2tw` と `s2twp` の違い**

`s2tw` は字形だけを変換し, 例えば "软件" は "軟件" になります. `s2twp` は台湾で一般的な語句にも置き換え, 例えば "软件" は "軟體" になります. `s2twi` は `s2twp` の別名です.

**スクリプトがプラグインの不足を報告する場合**

本プラグインがインストールされ, AutoJs6 の "プラグインセンター" で有効になっていることを確認してから, スクリプトを再実行してください. AutoJs6 の再起動は不要です.

すべてのメソッドと変換タイプは [AutoJs6 ドキュメント > OpenCC](https://docs.autojs6.com/#/opencc), その他の情報は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Hanzi-CC) を参照してください.
