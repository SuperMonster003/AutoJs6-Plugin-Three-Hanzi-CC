3-Hanzi CC - автономный конвертер китайского текста на основе OpenCC. Он преобразует текст между упрощенным и традиционным китайским, традиционным письмом Гонконга и Тайваня и японским синдзитай. Его можно использовать отдельно из лаунчера, а скриптам AutoJs6 он предоставляет глобальный объект `opencc`.

### Начало работы

1. Откройте 3-Hanzi CC из лаунчера и введите текст в поле "Исходный текст" или нажмите "Вставить", чтобы взять его из буфера обмена.
2. Выберите направление в списке "Тип преобразования" и нажмите "Преобразовать".
3. Посмотрите итог в поле "Результат" и нажмите "Копировать" или "Поделиться".
4. В скриптах AutoJs6 вызывайте глобальный объект `opencc` напрямую; пример приведен ниже.

### Основные возможности

- **14 преобразований**: охватывают основные направления между упрощенным, традиционным, гонконгским и тайваньским традиционным письмом и японским синдзитай. Типы с пометкой "Тайваньская терминология" заменяют и слова, например "鼠标" становится "滑鼠".
- **Быстрое редактирование**: "Инвертировать" переключает на обратное направление, "Поменять" меняет местами исходный текст и результат, "Очистить" удаляет текст.
- **Автономное преобразование**: преобразование выполняется на устройстве по встроенным словарям и не требует сети; текст не отправляется и не сохраняется.
- **Персонализация**: можно настроить язык, темную тему, цвет темы и значок запуска. Если включено "Запоминать тип преобразования", при следующем открытии восстанавливается последний тип преобразования.
- **Инструмент плагина**: в AutoJs6 6.8.0 или новее плагин также предоставляет инструмент `opencc_convert`, который могут вызывать плагины вроде MCP Server и API `plugins.tools` в скриптах.

### Использование в скриптах

В скриптах AutoJs6 глобальный объект `opencc` доступен без импорта. Для каждого типа преобразования есть метод с тем же именем, а `convert` принимает тип аргументом:

```js
console.log(opencc.s2t("汉字转换"));     // => 漢字轉換
console.log(opencc.t2s("漢字轉換"));     // => 汉字转换
console.log(opencc.s2twp("鼠标和软件")); // => 滑鼠和軟體
console.log(opencc.convert("汉字转换", "S2T")); // => 漢字轉換
```

- Типы преобразования нечувствительны к регистру, например `S2T`, `S2TWP`, `HK2S` и `T2JP`. Составные методы, такие как `s2jp` и `hk2tw`, выполняют несколько преобразований подряд.
- Скрипты Node.js подключают его через `require('autojs6:opencc')`, скрипты Bun используют `host.opencc`; методы те же, и все возвращают Promise.

### Требования

- Android 7.0 или новее. Для отдельной работы из лаунчера AutoJs6 не нужен.
- Скриптам нужен AutoJs6 6.7.1 Alpha4 или новее, а этот плагин должен быть включен в разделе "Центр плагинов".
- Скриптам Node.js нужен плагин Node.js Runtime 1.7.0 или новее; скриптам Bun нужен плагин Bun Runtime 0.2.6 или новее, при этом `text.opencc` на его странице настроек должен оставаться включенным (включен по умолчанию).
- Разрешение на доступ к сети используется только для проверки обновлений приложения. "Автоматически проверять обновления" включено по умолчанию, проверяет не чаще одного раза в 12 часов и отключается в разделе "Настройки".

### Частые вопросы

**Использование без AutoJs6**

Откройте 3-Hanzi CC из лаунчера, чтобы преобразовать текст; AutoJs6 нужен только для вызова `opencc` из скриптов.

**Разница между `s2tw` и `s2twp`**

`s2tw` преобразует только начертание знаков, например "软件" становится "軟件"; `s2twp` также заменяет слова на принятые на Тайване, например "软件" становится "軟體". `s2twi` - псевдоним `s2twp`.

**Если скрипт сообщает об отсутствии плагина**

Убедитесь, что этот плагин установлен и включен в разделе "Центр плагинов" AutoJs6, затем снова запустите скрипт. Перезапускать AutoJs6 не нужно.

Все методы и типы преобразования описаны в разделе [Документация AutoJs6 > OpenCC](https://docs.autojs6.com/#/opencc), остальные сведения - на [странице проекта](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Hanzi-CC).
