Плагин OpenCC (OpenCC Plugin) добавляет в AutoJs6 преобразование китайского текста на основе [OpenCC](https://github.com/BYVoid/OpenCC). После установки плагина глобальный объект `opencc` в скриптах AutoJs6 сразу готов к работе: одна строка кода преобразует текст между упрощенным китайским, традиционным китайским, гонконгским традиционным, тайваньским традиционным и японским синдзитай, без импорта модулей и без доступа к сети.

### Быстрый старт

После установки следующий скрипт запускается как есть; в комментариях показан ожидаемый вывод:

```javascript
console.log(opencc.s2t("汉字转换"));     // => 漢字轉換
console.log(opencc.t2s("漢字轉換"));     // => 汉字转换
console.log(opencc.s2twp("鼠标和软件")); // => 滑鼠和軟體
console.log(opencc.convert("汉字转换", "S2T")); // => 漢字轉換
```

### Типы преобразования

Метод `convert` и одноименные сокращенные методы поддерживают следующие 14 стандартных типов преобразования OpenCC, где S означает упрощенный китайский, T — традиционный (стандарт OpenCC), HK — гонконгский традиционный, TW — тайваньский традиционный, а JP — японский синдзитай:

```text
S2T   T2S   S2TW  TW2S  S2TWP  TW2SP  S2HK
HK2S  T2TW  TW2T  T2HK  HK2T   T2JP   JP2T
```

Типы с суффиксом `P` помимо познакового преобразования выполняют и замену лексики, поэтому результат звучит естественно для местных читателей; типы без `P` преобразуют только формы иероглифов, не затрагивая лексику.

### Быстрая самопроверка

Убедившись, что плагин установлен и включен в центре плагинов, выполните этот однострочный скрипт для сквозной проверки:

```javascript
console.log(opencc.s2t("汉字转换"));
```

Вывод `漢字轉換` означает, что вся цепочка плагина работает. Если скрипт завершается ошибкой, действуйте по сообщению: установите этот плагин, если сообщается об отсутствии плагина; включите соответствующий переключатель в центре плагинов, если плагин отключен или не авторизован; обновите AutoJs6, если требуется более новый хост.

Полный список методов и справку по типам преобразования см. в [документации AutoJs6 OpenCC](https://docs.autojs6.com/#/opencc) и [README проекта](https://github.com/SuperMonster003/AutoJs6-Plugin-OpenCC).
